Images the site expects (put them here with these exact filenames):

  hero-poster.jpg              First frame still of the hero video,
                               shown while the video is loading and
                               on browsers that block autoplay.
                               ~1920x1080, JPG, ~300 KB.

  last-call-hero-mobile.jpg    Portrait, ~1200x900.
  last-call-hero-desktop.jpg   Landscape, ~1920x1080.

  og-default.jpg               1200x630 default social share image
                               (used when OpenGraph image isn't
                               overridden by a specific page).

Keep JPG for photographic content, PNG only for graphics with hard
edges or transparency. All should be optimised — ImageOptim or
squoosh.app will drop file size by 40–70% with no visible loss.
